# Loja Clonia

Sistema web em desenvolvimento para gerenciar uma loja de roupas,
com foco em produtos, estoque, vendas e caixa.

## Objetivo

Desenvolver um sistema de gestão para lojas de roupas e aprofundar
meus conhecimentos em JavaScript, desenvolvimento web e banco de dados,
partindo da minha experiência com Progress ABL.

## Tecnologias utilizadas

- JavaScript
- Node.js
- PostgreSQL
- HTML
- Git e GitHub

## Funcionalidades implementadas

- Cadastro de produtos por modelo, tamanho e cor.
- Validação dos campos obrigatórios e tamanhos permitidos.
- Tratamento de produtos duplicados.
- Consulta de produto por código.
- Listagem de produtos com filtro por modelo.
- Organização do servidor em funções.
- Página HTML separada do código do servidor.

## Próximas etapas

- Movimentações e histórico de estoque.
- Cadastro de clientes.
- Registro de vendas e baixa de estoque.
- Controle de caixa.
- Relatórios.
- Melhorias na interface com CSS.

## Situação do projeto

Em desenvolvimento, com implementação gradual das funcionalidades.
Atualmente, a aplicação é executada localmente.
